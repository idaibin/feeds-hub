# Editorial Guidelines

本目录维护 Feeds Hub 的正文、标题、摘要和 frontmatter 写作规则。

## 文件

- `content-format.md`：内容格式、主题正文结构和禁用表达。

## 基本原则

- 只写事实，不写主观判断。
- 不写“为什么重要”类段落。
- 不把信息流写成观点文章。
- 不提供投资建议、赛事预测或产品成功判断。
- 可以记录市场情绪、赛程节点、确认事实和待确认事实。

## 自动任务读取要求

生成 Markdown 前必须读取：

```text
docs/editorial/content-format.md
```

正文格式必须服从该文件；主题范围仍以 `docs/topics/<category>.md` 为准，信息来源仍以 `docs/sources/<category>.md` 为准。
