# AI Sources

## Category

`ai`

## 信息目标

AI 主题优先获取模型、产品、研究、工具链和政策的可验证更新，避免追逐无来源爆料。

关注：

- 模型发布、模型卡、API、产品更新
- 研究论文、benchmark、开源模型和框架
- AI IDE、Agent、开发者工具和基础设施
- 芯片、数据中心、推理服务、云平台
- 政策、安全、标准和企业战略

## 优先来源

1. 官方公司博客、产品公告、开发者文档、模型卡、API 文档。
2. GitHub release、仓库 README、commit、issue、discussion、security advisory。
3. arXiv、ACL、NeurIPS、ICLR、ICML、CVPR 等论文或会议资料。
4. 标准组织、监管机构、政府公开文件。
5. 云平台和芯片厂商官方文档、release note、技术博客。

## 次级来源

1. Reuters、The Verge、TechCrunch、VentureBeat、Wired、Bloomberg、Financial Times 等科技和商业报道。
2. Latent Space、The Batch、Hacker News 讨论，必须能追溯到原始资料。
3. Maintainer blog、工程团队博客、开发者社区文章，前提是有实测、代码或官方链接。

## 可参考热度来源

只用于判断关注度：

- GitHub stars、forks、release 下载、issue 活跃度
- Hacker News、Reddit、X、知乎、少数派、V2EX 等讨论量
- 产品等待名单、API 使用者反馈、开发者迁移讨论
- 模型评测复现、第三方 benchmark 讨论

## 禁止来源

- 无原始链接的模型爆料。
- AI 摘要站二次转述。
- 没有代码、论文或官方说明的 benchmark 截图。
- 夸大能力的宣传帖。
- 未核验的内部邮件、聊天截图或路线图截图。

## 时间窗口

- 模型、产品、API、工具发布：发布后 48 小时内优先。
- 论文和开源项目：出现明确发布、代码或广泛讨论后 72 小时内优先。
- 政策和安全事件：官方文件或可信报道确认后 48 小时内优先。

## 热度判断

AI 内容判断是否写入看：

- 是否有明确发布、论文、代码、政策或产品变化。
- 是否影响开发者、产品用户、企业采用或行业治理。
- 是否有网络讨论热度，但热度必须建立在可核验事实上。
- 是否能区分事实、报告、推测和观点。

## 跳过规则

- 只有社交讨论，没有官方、代码、论文或可信报道。
- benchmark 不能复核来源或上下文。
- 内容只是旧消息改写，没有新增事实。
- 能力、安全或市场影响被明显夸大。
