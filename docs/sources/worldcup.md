# World Cup Sources

## Category

`worldcup`

## 信息目标

世界杯主题优先获取赛事信息，而不是泛泛足球评论。

关注：

- 赛程
- 赛果
- 晋级和淘汰
- 分组和淘汰赛路径
- 官方规则、场地、开球时间调整
- 球员伤停、阵容和赛后关键事实

## 优先来源

1. FIFA 官方网站、match centre、schedule、match report。
2. 赛事官方社交账号或官方新闻稿。
3. 各国家队或足协官方公告，用于阵容、伤停和官方声明。
4. 主办城市或场馆官方公告，用于场地和运营信息。

## 次级来源

1. Reuters、AP、BBC Sport、ESPN、The Guardian、The Athletic 等体育报道。
2. 可靠体育数据源，前提是能明确更新时间。
3. 主流媒体的赛后报道和战术复盘。

## 可参考热度来源

只用于判断关注度：

- 社交平台比赛讨论
- 搜索趋势
- 体育社区讨论
- 视频平台高播放赛后片段
- 球员和球队相关讨论热度

## 禁止来源

- 无来源的转会或阵容传闻。
- 球迷论坛单方面爆料。
- 未核验的比分截图。
- 只给预测、不提供事实来源的内容。
- 把多个比赛结果混成一条综合信息的来源。

## 搜索关键词模板

```text
FIFA World Cup <team A> <team B> result
FIFA World Cup <team A> <team B> schedule
FIFA match report <team A> <team B>
<team> World Cup qualification knockout path
<player> World Cup injury official
```

中文搜索可用：

```text
世界杯 <球队A> <球队B> 赛果
世界杯 <球队A> <球队B> 赛程
世界杯 晋级 形势 官方
世界杯 球员 伤停 官方
```

## 时间窗口

- 赛程前瞻：比赛前 72 小时内优先。
- 比赛结果：完赛后 12 小时内优先。
- 晋级、淘汰、规则或场地变更：官方确认后 24 小时内优先。

## 信息价值判断

世界杯内容不强行写“为什么重要”。判断是否写入看：

- 是否是当前赛事周期内的赛程或结果。
- 是否影响晋级、淘汰、分组或下一轮对阵。
- 是否有明确官方时间、比分或状态。
- 是否符合用户当前关注的世界杯主题。

## 跳过规则

- 只有预测，没有官方赛程或结果。
- 只有情绪化评论，没有新增事实。
- 同一比赛状态已写入，没有新的赛果、晋级或官方变化。
- 来源之间对比分或开球时间存在冲突且无法确认。
