# Global Sources

## Category

`global`

## 信息目标

全球重点主题优先获取具有公共影响、跨地区影响或长期背景价值的事件，不追逐低价值碎片新闻。

关注：

- 政策、外交、法院、监管、央行、国际组织
- 经济、能源、供应链、气候、公共安全、社会事件
- 重要报告、官方决定、国际会议、重大调查
- 对科技、市场、产品或开源生态有外溢影响的综合新闻

## 优先来源

1. 政府、法院、监管机构、央行、联合国、世界银行、IMF、WHO、WTO 等官方文件。
2. 官方新闻稿、裁决文件、政策原文、会议声明、报告全文。
3. 国家统计机构、公共数据库和机构发布的数据。

## 次级来源

1. Reuters、AP、BBC、Financial Times、The Guardian、Nikkei、Wall Street Journal、Bloomberg 等国际报道。
2. 当地可靠媒体，用于补充本地事实和现场信息。
3. 专业机构报告，前提是报告可公开核验。

## 可参考热度来源

只用于判断关注度：

- 多家主流媒体同时报道
- 官方机构连续更新
- 社交平台讨论升温
- 对市场、科技、供应链或公共生活产生后续影响
- 国际组织、政府或企业出现后续回应

## 禁止来源

- 无来源社交截图。
- 明显立场化的单边评论。
- 没有原始材料的二手转述。
- 将局部事件夸大成全球事件的标题党内容。
- 无法确认地点、时间、主体的突发消息。


## 时间窗口

- 官方政策、裁决、报告：发布后 48 小时内优先。
- 突发公共事件：可信来源确认后 12 小时内优先。
- 长期议题后续：必须有明确新文件、新决定或新数据。

## 热度判断

全球重点内容判断是否写入看：

- 是否具有明确公共影响或跨地区影响。
- 是否来自官方来源或多家可信媒体交叉确认。
- 是否影响政策、市场、社会、科技或供应链。
- 是否有持续关注价值，而不是一次性噪音。

## 跳过规则

- 事实尚未确认。
- 只有评论，没有新增事实。
- 与用户关注方向关联弱。
- 来源之间冲突且无法确认核心事实。
- 事件影响范围有限，缺少进入综合重点的必要性。
