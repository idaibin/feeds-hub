# LOL Sources

## Category

`lol`

## 信息目标

LOL 主题优先获取赛事节点和官方竞技信息，而不是泛泛电竞讨论。

关注：

- LPL、MSI、Worlds、First Stand 等赛事赛程
- 单场赛果
- 晋级、淘汰、分组、抽签、赛制
- 阵容名单、人员变动、禁赛、规则调整
- 版本变化对赛事的明确影响

## 优先来源

1. LoL Esports 官方赛程和赛事页面。
2. Riot Games 官方公告、赛事规则、赛制说明。
3. LPL、MSI、Worlds 等赛事官方账号或官网。
4. 战队官方公告，用于阵容、人员和声明。

## 次级来源

1. Leaguepedia，用于赛程、赛果、分组和战队信息交叉验证。
2. Liquipedia，用于赛事结构和历史记录辅助验证。
3. Upcomer、Dot Esports、Dexerto、Inven Global 等电竞报道，前提是能链接到官方或可核验资料。
4. 主流媒体的电竞专题报道。

## 可参考热度来源

只用于判断关注度：

- 社交平台比赛讨论
- 赛事直播观看热度
- 战队和选手讨论量
- 社区赛后讨论
- 视频平台高播放赛后内容

## 禁止来源

- 未证实的训练赛传闻。
- 无来源爆料号。
- 只基于选手直播片段的推断。
- 未核验的赛程截图。
- 粉丝站单方面整理且无法追溯来源的内容。

## 搜索关键词模板

```text
LoL Esports <tournament> schedule
LoL Esports <team A> <team B> result
LPL <team> roster official
Riot Games <tournament> format rules
Leaguepedia <tournament> bracket
```

中文搜索可用：

```text
LPL <战队A> <战队B> 赛程
LPL <战队A> <战队B> 赛果
英雄联盟 MSI 赛程 官方
英雄联盟 世界赛 赛制 官方
<战队> 阵容 官方公告
```

## 时间窗口

- 赛程前瞻：比赛前 72 小时内优先。
- 赛果：完赛后 12 小时内优先。
- 阵容、赛制、禁赛或规则：官方确认后 24 小时内优先。

## 信息价值判断

LOL 内容不强行写“为什么重要”。判断是否写入看：

- 是否是当前赛事周期内的赛程、赛果或晋级节点。
- 是否影响下一场、下一轮、分组或战队状态。
- 是否来自官方或可交叉验证的赛事资料。
- 是否符合用户对 LOL 赛事的持续关注。

## 跳过规则

- 只有预测，没有官方赛程或赛果。
- 只有社交讨论，没有新增赛事事实。
- 同一比赛或阵容事实已写入。
- 多场比赛被混成一条且无法形成单一事件。
