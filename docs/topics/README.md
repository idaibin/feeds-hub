# Topics

本目录按主题维护 Feeds Hub 的关注范围、输出格式和可选信息来源。

自动更新任务默认读取本目录，而不是把所有主题规则集中写入 `docs/automation/feeds-hub-update.md`。

## 文件

- `worldcup.md`：世界杯
- `lol.md`：LOL 赛事
- `stock.md`：股市简报
- `ai.md`：AI 科技
- `global.md`：全球重点
- `rust.md`：开源与 Rust
- `product.md`：创业与产品设计

## 单主题文档格式

每个主题文档固定包含：

1. 主题 ID
2. 关注内容
3. 输出格式
4. 信息来源，来源可选，但事实必须可追溯
5. 跳过条件
