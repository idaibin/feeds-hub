7 月 8 日核验 GitHub 页面时，`addyosmani/agent-skills` 显示 72.1k stars、7.8k forks 和 308 commits；仓库描述为面向 AI coding agents 的 production-grade engineering skills。

README 将仓库内容定义为工程流程技能包：用 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/webperf`、`/code-simplify`、`/ship` 8 个 slash commands 覆盖从需求定义到上线的开发生命周期，并强调每个任务仍应测试驱动、逐项验证。

开发者价值在于它把资深工程师常用的质量门禁、任务拆分、测试、评审和发布流程打包成可移植 Markdown 技能。README 同时说明 open `skills` CLI 可安装到 Claude Code、Cursor、Codex、Copilot、Cline 等 70+ agents；本条只记录当前仓库页和 README 的可核验状态，不写作 GitHub 官方 Trending 排名。
