Vercel Changelog 7 月 3 日显示，Agent Runs 已接入 Vercel MCP 和 CLI，可查询项目运行、列出最近 runs、查看元数据并检索完整 trace。该能力面向部署在 Vercel 的 eve traces。

Vercel 列出的 MCP 工具覆盖项目发现、运行列表、运行详情和 trace 读取；CLI 同步提供 projects、list、inspect 和 trace 子命令，并支持 JSON 输出。
