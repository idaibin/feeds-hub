arXiv 论文在 Microsoft 早期 2026 推广 Claude Code 与 GitHub Copilot CLI 的场景中，研究命令行 AI 编程代理的采用、留存和产出代理指标。论文使用合并 PR 作为输出代理，并明确说明该指标不等同于代码价值。

论文称，采用者在观察窗口内合并 PR 数约高 24%，但结果用于描述组织内工具采用信号和留存差异，不应被解读为通用生产率结论。
