Reuters 7 月 7 日报道，Perplexity 已确认计划使用 Nvidia 新款 Vera CPU；Perplexity 企业与基础设施副总裁 Nate Kupp 称，Vera 在 AI Agent 编码任务中比传统 CPU 快约 1.5 倍。

这条进展说明 Nvidia 正把 AI 基础设施从 GPU 扩展到更通用的 CPU 市场。Reuters 写道，Vera 面向的是长期由 Intel 和 AMD 主导的 CPU 领域，Nvidia 预计该 CPU 在本财年结束前带来 200 亿美元销售额。

采购规模仍未披露。Perplexity 未说明将购买多少 Vera CPU；Reuters 同时记录，Nvidia 此前已披露 OpenAI、Anthropic 和 Oracle 也计划使用其 CPU，因此本条只确认 Perplexity 的采用意向和公开测试表述，不扩写为实际部署完成。
